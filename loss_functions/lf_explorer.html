Key Concepts ▾
What is a loss function? A loss function measures how far a model's prediction is from the true answer. Training minimises this score — so the choice of loss function directly shapes what the model learns to optimise.
Why MSE penalises outliers more than MAE: MSE squares the error, so a prediction that is 10× further from the truth contributes 100× as much loss. MAE uses the absolute error, so that same outlier contributes only 10× as much — making MAE far more robust to extreme values.
Why cross-entropy is used for classification: Classification produces probabilities. Cross-entropy measures how surprised you are by the true label given your probability — predicting 0.01 for the correct class incurs enormous loss, creating a steep gradient that pushes probabilities toward 1 for the right class.
What the gradient of the loss tells the optimizer: The gradient ∂L/∂ŷ tells gradient descent how much to adjust the prediction. A large gradient means you are far from the minimum — the optimizer takes a big corrective step. Near the minimum the gradient shrinks, slowing updates and allowing fine convergence.
How Huber loss bridges MSE and MAE: Huber uses MSE for small errors (where quadratic is smooth and easy to optimise) and MAE for large errors (where quadratic would over-emphasise outliers). A threshold δ controls where the switch happens — Huber gives the best of both worlds for noisy regression problems.
