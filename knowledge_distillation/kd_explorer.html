What's happening?
Select teacher and student architectures, set the temperature τ and loss weight α, then press Play to watch the student learn from the teacher's soft predictions.
Key Concepts ▾
Knowledge distillation: transfer learning where a large pre-trained teacher network guides a smaller student network — the student learns not just the correct labels but the teacher's full probability distribution over all classes.
Soft labels: instead of hard one-hot labels (100% class A, 0% everything else), the teacher provides soft probabilities over all classes — e.g., 70% cat, 20% dog, 10% fox. This reveals how the teacher "thinks" about similarity between classes.
Temperature τ: divides logits before softmax — higher τ flattens the distribution, making soft labels softer and more informative. At τ=1, the teacher's output may be nearly one-hot; at τ=5 the probability spreads reveal inter-class similarities.
Loss weight α: controls the trade-off between hard label loss (cross-entropy with true labels) and soft label loss (KL divergence with teacher's soft predictions). α=0.5 balances both; α→1 relies almost entirely on soft labels.
Why distillation beats scratch: the teacher's soft labels encode dark knowledge — relationships between similar classes — that hard labels cannot capture. The student receives a richer training signal, converging to better accuracy with fewer parameters than the teacher.
