Key Concepts ▾
Saliency maps: compute ∂f/∂x — the gradient of the model output with respect to each input pixel. Large absolute gradient = the model is sensitive to that pixel at this input. Fast to compute but noisy near saturated activations.
Why vanilla gradients are noisy: gradients reflect local sensitivity, not contribution. Near saturation regions (ReLU dead zones, sigmoid tails) gradients vanish even when a feature genuinely influenced the output — the map can mislead.
Integrated gradients (Sundararajan et al.): accumulate gradients along a straight-line path from a baseline x′ to the input x: IG(x) = (x−x′) · ∫₀¹ ∂f(x′+α(x−x′))/∂x dα. This captures contributions at all activation levels, not just the endpoint.
Completeness axiom: IG attributions sum exactly to f(x) − f(x′). Every unit of prediction difference is "accounted for" by exactly one pixel's attribution. This makes IG attributions faithful — they are provably tied to the prediction gap.
GradCAM: weights each feature map's gradient globally (average over spatial dimensions), then forms a linear combination of feature maps. Produces a class-discriminative coarse localization map — useful for CNNs, less fine-grained than pixel-level methods.
