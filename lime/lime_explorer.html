Key Concepts ▾
What LIME is: LIME (Local Interpretable Model-Agnostic Explanations) explains any black-box classifier by fitting a simple linear model around a specific point of interest — the local behavior of a complex model is often much simpler than its global behavior.
Local linearity: even if a neural network draws a highly curved decision boundary globally, the boundary near one specific point can be well-approximated by a straight line. LIME exploits this by explaining the local behavior only.
Neighborhood radius: controls how far from the selected point LIME samples neighbors. Smaller radius → explanation is very local and may not generalize. Larger radius → smoother but less precise explanation.
Model-agnostic: LIME only requires the ability to query the model for predictions — it never looks inside the model. The same algorithm explains neural networks, random forests, SVMs, or any other classifier.
Feature weights: positive weight for feature xᵢ means increasing xᵢ pushes the prediction toward class 1; negative weight means increasing xᵢ pushes toward class 0. Larger magnitude = stronger influence.

How LIME Works — 5-step algorithm
1
Select a point to explain
Pick any input point x* whose prediction you want to understand. This is the point whose local neighborhood LIME will explore.
2
Sample neighbors in the neighborhood
Randomly sample points z in the neighborhood of x* (within radius r), then query the black-box model f(z) to get their predicted classes.
3
Weight neighbors by proximity
Assign weight πₓ*(z) = exp(−d(x*,z)²/σ²) to each neighbor — points closer to x* get higher weight. This ensures the local model focuses on the immediate region.
4
Fit a weighted linear model
Minimize ξ(x) = argmin_{g∈G} L(f, g, πₓ*) + Ω(g) — find the simplest linear model g that best approximates f locally. The weights πₓ* ensure fidelity near x*.
5
Coefficients = the explanation
The linear model coefficients w₁, w₂ are the LIME explanation. w₁ > 0 means feature x₁ pushes toward class 1; w₁ < 0 means it pushes toward class 0. Magnitude shows importance.
